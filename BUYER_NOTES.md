# EntropyMint — Buyer Notes

**What you get**
- Single-file Python CLI: `entropymint.py`
- Full test suite
- README + MIT License
- Zero dependencies — runs anywhere with Python 3.8+

**How to run**
```bash
python3 entropymint.py mint --mode password --length 20
python3 entropymint.py mint --mode passphrase --words 5 --json
python3 entropymint.py analyze "your-secret-here" --json
python3 entropymint.py health
```

**Requirements**
- Python 3.8+
- No internet, no packages to install
